# 常见问题

## 后台已经保存，博客为什么没变化？

先确认使用的是哪个按钮：

- “保存草稿”只会把内容放入 D1 的“待提交”。
- “提交到 GitHub”才会改变已发布内容。

如果 GitHub 已有 commit，再到静态托管平台检查构建状态。后台不负责确认 Vercel 或其他平台是否部署成功。

## 提交时提示冲突

说明草稿创建后，GitHub 中的同一内容又发生了变化。

1. 先查看 GitHub 最新版本。
2. 把需要保留的改动合并到草稿。
3. 重新提交。

只有确认草稿应完全覆盖最新版本时，才使用“强制覆盖”。

## 配置页显示为空或无法读取

后台只读取受支持的字面量配置对象。若把对象改成函数调用、复杂表达式或不受支持的代码结构，表单可能无法解析。

恢复为普通对象或数组后，再重新打开配置页。运行 `pnpm type-check` 不能替代后台解析检查，两者需要同时通过。

## 导航栏只能改链接，不能改分组

这是当前设计。后台“基础组件 → 导航栏”负责搜索设置与链接预设；顶层分组、下拉层级和顺序需要手动调整 `navBarConfig`。

## 页面开关已开启，导航中仍没有入口

页面开关只决定页面是否可访问。导航还需要使用对应的链接预设，或手动添加一个指向该页面的链接。

反过来，如果链接设置了正确的 `pageKey`，关闭页面开关后它会自动隐藏。

## 侧边栏组件没有显示

依次检查：

1. 侧边栏总开关是否开启。
2. 当前屏幕宽度是否符合左侧、右侧或移动端组件区域。
3. 组件自身 `enable` 是否开启。
4. `showOnPostPage` 和 `hideOnNonPostPage` 是否与当前页面匹配。
5. 音乐、公告、动态等对应功能是否已经配置。

## 评论区没有显示

- 全局评论类型不能是 `none`。
- 当前服务地址和标识必须有效。
- 页面配置中的“显示评论”需要开启。
- 单篇文章的 `comment` 不能是 `false`。
- Giscus 还需要仓库 Discussions、分类和应用授权正确。

## 本地搜索没有结果

Pagefind 搜索索引在完整构建后生成。先运行：

```bash
pnpm build
pnpm preview
```

开发服务器中的搜索结果可能不完整。

## 随机封面一直失败

确认文章封面使用 `image: api`，并检查“功能配置 → 文章封面”：

- 随机封面总开关已开启。
- API 返回的是可直接访问的图片响应或重定向。
- 接口允许构建环境访问。
- 所有接口都失败时，网络日志中通常会有超时或状态码信息。

## 网络图片返回 403

这通常是图片服务的防盗链限制。可以：

- 换用允许外链的图片服务。
- 将图片保存为本地资源。
- 在“基础配置 → 站点配置 → 图片优化”中添加对应的不发送来源域名规则。

## 修改字体、代码主题或提醒框后没有生效

这些设置参与构建插件初始化。停止当前开发服务器后重新运行 `pnpm dev`，最终发布前再执行一次完整构建。

## 页脚 HTML 没有显示

“拓展功能 → 页脚”中的注入总开关必须开启。页脚 HTML 内容和开关是两个独立子菜单。

## 看板娘遮挡按钮或移动端内容

- 换到另一侧角落。
- 调小画布尺寸或模型缩放。
- 调整边缘偏移。
- 开启移动端隐藏。
- 检查层级是否高于必要范围。

## 构建时间明显变长

常见原因包括：

- 开启 OpenGraph 图片生成。
- 添加大量需要 Astro 优化的图片。
- 加载多个远程字体和字重。
- 对大量本地字体执行子集化。
- 文章中包含大量 Mermaid 或 PlantUML 图表。

先关闭非必需的构建期功能，再逐项恢复，可以更快定位瓶颈。
