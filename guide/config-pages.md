# 页面

**入口：后台 → 页面**

这里管理动态、友链、相册和打赏页面。页面是否可以访问，由“基础配置 → 站点配置”中的页面开关决定。

## 动态

**入口：后台 → 页面 → 动态**  
**手动配置对象：`dynamicConfig`**

| 字段 | 说明 |
| --- | --- |
| 页面标题 | 留空时使用内置翻译 |
| 页面描述 | 留空时使用内置翻译 |
| 资料链接 | 点击动态头像或名称后的跳转地址 |
| 显示评论 | 为每条动态显示评论，需要先启用评论系统 |
| 每页数量 | 控制分页密度 |
| 数据地址 | 默认读取站点生成的动态 JSON，也可使用第三方接口 |

### Memos 数据源

启用 Memos 后，页面会从 Memos API 实时获取数据，并忽略普通数据地址。

- API 地址填写 Memos 实例地址。
- 用户标识使用 `users/用户名` 格式。
- Memos 服务必须允许博客域名跨域访问。

“页面 → 动态”只设置页面行为；具体动态内容从“发布动态”创建。

## 友链

**入口：后台 → 页面 → 友链**  
**手动配置对象：`friendsPageConfig`、`friendsConfig`**

### 页面设置

- 标题和描述留空时使用内置翻译。
- 自定义内容可以显示在友链列表下方。
- 评论区需要先启用全局评论系统。
- 随机排序开启后，每次加载会打乱已启用友链。

### 友链项目

| 字段 | 说明 |
| --- | --- |
| 名称 | 站点或作者名称 |
| 头像 | Logo、头像或站点图标地址 |
| 描述 | 一句话介绍 |
| 地址 | 友链目标 URL |
| 标签 | 用于补充类型或主题 |
| 权重 | 数值越大越靠前，仅在未随机排序时生效 |
| 启用 | 暂时隐藏时无需删除项目 |

后台对友链项目使用折叠卡片，默认只显示名称、摘要和启用状态。

## 相册

**入口：后台 → 页面 → 相册**  
**手动配置对象：`galleryConfig`**

每个相册项目包含：

| 字段 | 说明 |
| --- | --- |
| ID | 唯一标识，同时用于相册 URL 和图片目录 |
| 名称 | 相册标题 |
| 描述 | 相册简介 |
| 地点 | 拍摄或创作地点 |
| 日期 | `YYYY-MM-DD`，用于排序和展示 |
| 标签 | 分类和筛选用标签 |
| 封面 | 可选；未填写时优先查找 `cover.*`，否则使用第一张图片 |
| 密码 | 可选；设置后需要验证才能查看 |
| 密码提示 | 可选，需与密码一起使用 |

支持 JPG、PNG、WebP、AVIF 和 GIF。创建相册配置后，还需要在对应的相册资源目录中放入图片。

“瀑布流最小列宽”决定浏览器自动计算的列数：数值越小列数越多，数值越大单张图片越宽。

::: warning 相册密码的定位
相册密码适合阻止随手访问，不应当替代严格的私有存储和访问控制。不要把真正敏感的私人照片放入公开仓库。
:::

## 打赏

**入口：后台 → 页面 → 打赏**  
**手动配置对象：`sponsorConfig`**

### 页面设置

- 页面标题和描述留空时使用内置翻译。
- 用途说明应清楚告诉读者款项用途。
- 可以控制打赏者列表、评论区和文章底部打赏按钮。

### 打赏方式

| 字段 | 说明 |
| --- | --- |
| 名称 | 支付方式名称 |
| 图标 | Iconify 图标名 |
| 二维码 | 二维码图片地址 |
| 链接 | 在线支付或说明页面 |
| 描述 | 补充说明 |
| 启用 | 暂时隐藏时无需删除 |

二维码和支付链接可以只填写其中一个。发布前应在手机端实际测试扫码和跳转。

### 打赏者列表

打赏者项目通常包含名称、金额、日期和留言。只有在获得对方同意时才公开姓名、头像或留言。
